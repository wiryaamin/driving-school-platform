## How to update this document

When an integration's real-world status changes (e.g. `RESEND_API_KEY` gets set on the pilot project), update that row's **Configured**, **Pilot Ready**, and **Testing Status** columns, and clear or update the **Current Blockers** cell. Do not wait for a scheduled review — this table is only useful if it reflects reality at the moment someone reads it. If a status change reveals something that needs explaining in more depth than a table cell allows, add that explanation to `docs/INTEGRATION_CONFIGURATION_GUIDE.md`'s relevant chapter, not here.
